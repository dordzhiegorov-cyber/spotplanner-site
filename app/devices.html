Spotplanner · device viewer

You are looking at the development server (port 8081): every frame downloads an 8 MB debug bundle, so frames take a while and feel slow. For checking the look, run npm run preview in the repo root and open http://localhost:8082/devices.html — the production build loads in about a second per frame.

Each frame is the live app at that device's CSS resolution, so you can click through it. Frames load one after another; pick more devices to compare side by side. Palette and scheme apply inside the frames via ?palette=…&scheme=… and are remembered per browser (?palette=reset forgets). The app itself defaults to Daylight · Light.
